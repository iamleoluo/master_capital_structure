# MSTR × BTC × mNAV × CEBE 歷史對照系統

依 `MSTR_CEBE_歷史分析_建置規格.md` 建置。回答的核心問題:

> 「在 BTC = X 的情況下,mNAV = Y 對應到 MSTR 股價是多少?」

並且把 2025–2026 年優先股大量增發造成的結構性變化明確拆出來。

---

## 快速開始

```bash
python3 build_db.py                 # 抓日線 → 驗證資料源 → seed §5 → 算 mNAV 序列
python3 -m pytest tests/ -q         # 109 個測試,含 §6 全部驗證錨點
```

### 為什麼容差不是零

規格書 §6.1 寫「必須**精確**吻合」,附錄也標「已完全反解驗證」。**實測做不到逐分吻合**,
原因不在公式,在 FWP 自己的輸入:`usd_reserve` / `debt_otm` / `pref_otm` 只揭露到 $1M
精度,`fdso` 只寫 "~398.2M"。

`test_no_single_fdso_reproduces_table_exactly` 證明了這點:對每一列反解出能產生官方值的
FDSO 區間,六個區間**交集為空**。規格書給的 398,220,309 最差偏離 1.5 分(0.66bp);
最佳擬合值約 398,237,000(最差 0.4 分)。因此測試用 $0.02 / 1bp 容差 —— 這是公式正確
所能達到的最緊上限。

## 建置期發現的來源資料問題

全部保留原值並標記,未偷改。`python3 -m mstr_cebe.cli findings` 可完整列出。

1. **§5.9 的 2026-07-05 淨求償權 `~$21,000M` 是錯的。** 同一列的 claims% 38.3%、
   BPS 227,057、CEBE 140,200 三個欄位彼此一致,但一致於 **$19.63B / 371.6M 股**
   (正好是 §6.3 自己列給 cebetracker 的金額,以及 §5.4 的 2026-06-30 basic 股數)。
   用 $21,000M 反算 claims% 得 40.95%,與同列差 2.6 個百分點。

2. **§8.2 說有兩個股數分母,實際上是三個。** §7.3 對照表的「Basic 基準 1.0x → ~$137」
   用的是 basic shares(394.2M),不是 Gross BPS 的 assumed diluted(423.8M,得 $127.46)。
   差 7%。`PriceBasis` 因此分成 `GROSS` 與 `BASIC` 兩個獨立基準。

3. **$543 是盤中高點,不是收盤價。** 2024-11-21 收盤為 $397.28(實測)。§1.3 把這個盤中
   高點與終點的**收盤價** $97.33 相比。以收盤對收盤重算,股價項是 ×0.245(log −1.406)
   而非 ×0.179(log −1.72)。**結論方向完全不變**,但壓縮幅度被高估約 37%。

4. **2024 年的求償權由「價內可轉債」主導,不是發債規模。** §5.9 說 2024-Q4 淨求償權只有
   $1.4B,而 §5.3 說 2025 年底可轉債有 $8.21B —— 差一個數量級。解釋是 cebetracker 排除
   價內可轉債(§8.8 的同一個道理),而 2024 年底 MSTR 在 $290–543、轉換價 ~$143,幾乎
   全部價內。**這強化了規格書自己的判斷:§5.3 的各系列轉換價是最該優先補的缺口** ——
   2024→2025 淨求償權暴增有很大一部分是既有可轉債從價內變價外,不是新發債。

5. **§5.10 的 2025-12-01 把 MSTR 低點配上了另一天的 BTC 低點。** 該日 BTC 實際收盤
   $86,286;最接近 ~$80,000 的低點($80,600)出現在 2025-11-21。照抄會讓 mNAV 高估 8.6%。

6. **§5.4 的 FDSO 只有一個時點。** 因此 `diluted` 與 `company` 兩個變體在日頻序列裡幾乎
   沒有覆蓋。§5.4 的「稀釋後加權平均股數」是**期間加權平均**,不是期末在外股數,不能當
   FDSO 用 —— `core` 在缺 FDSO 時**拋錯而非猜測**,`all_mnavs` 跳過該變體。

7. 規格書的兩處算術筆誤(不影響結論):§6.1 驗算示範寫 `= $92.115`,實為 $92.11005;
   §6.2 寫 Net BPS `= 143,280`,實為 143,297(與官方 143,292 的差距其實比原文算的更小)。

## 已知缺口(依優先序)

1. **可轉債各系列轉換價與到期日**(§5.3)—— 最大缺口。發現 4 顯示它比規格書原本評估的
   還關鍵:沒有它,2024–2025 的 claims 軌跡無法正確重建。
2. **各期期末 FDSO**(§5.4)—— 補上才能讓 diluted / company mNAV 有完整時間序列。
3. **2025 年三季的分系列優先股餘額**(§5.2)—— 目前為 `[EST]`。
4. 2024-12-31 之前的資本結構 —— 目前一律 backward-fill 並標記推估。

  會在堆疊圖上造成假的斷崖。
